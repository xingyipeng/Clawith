# 信息调研与报告生成

## 触发场景
用户说"帮我调研 X"、"搜索一下 Y"、"整理一份关于 Z 的报告"时启用。

---

## 强制工作流（不得跳过任何步骤）

### Step 1 — 明确范围
在搜索前，向用户确认：
- 调研深度：概览（3-5 条来源）还是深度（10+ 条）？
- 输出格式：飞书文档 / 直接回复 / 写入 workspace 文件？
- 时效性要求：是否需要最新数据（近 30 天）？

### Step 2 — 执行搜索（必须调用工具，不得靠记忆）
```
jina_search(query="<具体搜索词>")
```
- 至少执行 2 次不同角度的搜索
- 记录每条来源的 URL（将出现在最终报告中）

### Step 3 — 精读关键来源
对最相关的 2-3 个 URL：
```
jina_read(url="<URL>")
```
不得在未读原文的情况下引用内容。

### Step 4 — 生成报告
根据 Step 1 约定的格式：

**选项 A：飞书文档**
```
feishu_doc_create(title="<报告标题>")
feishu_doc_append(document_token="<真实token>", content="<内容>")
```
→ 把工具返回的真实链接发给用户，不得自行构造链接

**选项 B：写入 workspace 文件**
```
write_file(path="workspace/<报告名称>_<日期>.md", content="<内容>")
```

**选项 C：直接回复**（仅限简短摘要，不超过 500 字）
→ 在回复中必须标注来源 URL

### Step 5 — 汇报结果
告知用户：
- 搜索了哪些关键词
- 找到了几条来源
- 报告存放位置（真实链接或文件路径，来自工具返回值）

---

## ❌ 禁止事项
- 不得在未调用 jina_search 的情况下直接回答"根据我所知..."
- 不得引用无法提供 URL 的信息（"据说"、"一般认为"等模糊表述）
- 不得在未调用 feishu_doc_create 的情况下说"我已创建了飞书文档"
- 不得自行构造文档 URL（必须使用工具返回的真实链接）
